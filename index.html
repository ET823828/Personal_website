Research Interests

My research focuses on building efficient and reliable AI systems through cross-stack optimization and automated systems development.

  • Systems and architecture for emerging AI workloads. I study efficient execution across models, runtimes, and hardware, with a recent focus on embodied AI and its real-world deployment.
  • Reliable code generation and optimization with coding agents. I study how to make agent-generated code more reliable by improving how human intention is specified, evaluated, and fed back to agents.

Publications

Behavioral Test Diversity: Quantifying Test Suite Diversity Through Agentic Code Repair

Yichong Zhang, Genghan Zhang, Zishen Wan, Kunle Olukotun, Olivia Hsu

Submitted to ICLR 2027 · Under review

More tests do not necessarily provide coding agents with more diverse behavioral specifications. BTD measures diversity by checking whether a repair for one test also satisfies others, and uses this signal to guide test-suite pruning and expansion.

Serving Agentic Workflows with a Physical-Plan Compiler and Adaptive Runtime

Jiayi Qian, Yichong Zhang, Hanchen Yang, Chun Tao, Souvik Kundu, Zishen Wan, Tushar Krishna

Submitted to ASPLOS 2027 · Under review

arXiv

Dyserve jointly optimizes model selection, verification policies, and backend assignment for agentic workflows. A profile-guided compiler and an adaptive runtime coordinate these decisions as serving load changes, balancing output quality, latency, and throughput.

Efficient and Adaptable Overlapping for Computation and Communication via Signaling and Reordering

Ke Hong, Xiuhong Li, Minxu Liu, Qiuli Mao, Tianqi Wu, Zixiao Huang, Lufang Chen, Zhong Wang, Yichong Zhang, Zhenhua Zhu, Guohao Dai, Yu Wang

EuroSys, 2026

arXivCode

FlashOverlap reduces communication overhead in multi-GPU workloads by allowing completed output tiles to be communicated while computation continues. Tile-level signaling and data reordering enable fine-grained overlap while reusing existing NCCL communication primitives.

PAROAttention: Pattern-Aware ReOrdering for Efficient Sparse and Quantized Attention in Visual Generation Models

Tianchen Zhao, Ke Hong, Xinhao Yang, Xuefeng Xiao, Huixia Li, Feng Ling, Ruiqi Xie, Siqi Chen, Hongyu Zhu, Yichong Zhang, Yu Wang

NeurIPS, 2025

arXivProject

PAROAttention reorganizes irregular visual attention patterns into hardware-friendly blocks through token reordering. This structure enables effective sparsification and low-bit quantization, accelerating image and video generation while maintaining generation quality.
